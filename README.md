🎯 O que é este projeto?

O Eleições 2026 - Painel de Análise é uma aplicação web independente desenvolvida para visualizar, filtrar e analisar os dados oficiais de apuração das Eleições 2026, consumindo diretamente a API pública do Tribunal Superior Eleitoral (TSE).

📡 Fontes de Dados

Este projeto utiliza exclusivamente duas fontes oficiais:

API de Resultados do TSE: dados de apuração em tempo real
API de Fotos do TSE: fotos oficiais dos candidatos
Não consultamos portais de notícias, institutos de pesquisa, partidos políticos ou qualquer outra fonte externa.

⚠️ Aviso Importante

Este é um projeto pessoal e independente. Não possui qualquer vínculo com o TSE, Justiça Eleitoral, partidos políticos ou candidatos. Todos os dados exibidos são de domínio público e fornecidos oficialmente pelo TSE.
