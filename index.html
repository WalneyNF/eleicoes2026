ℹ️ Sobre o Projeto

🎯 O que é este projeto?

O Eleições 2026 - Painel de Análise é uma aplicação web independente desenvolvida para visualizar, filtrar e analisar os dados oficiais de apuração das Eleições 2026, consumindo diretamente a API pública do Tribunal Superior Eleitoral (TSE).

👨‍💻 Desenvolvedor

Walney Moreira Klein

📧 walneyk@hotmail.com

🐙 github.com/walneynf

📡 Fontes de Dados

Este projeto utiliza exclusivamente duas fontes oficiais:

  • API de Resultados do TSE: dados de apuração em tempo real
  • API de Fotos do TSE: fotos oficiais dos candidatos

Não consultamos portais de notícias, institutos de pesquisa, partidos políticos ou qualquer outra fonte externa.

⚠️ Aviso Importante

Este é um projeto pessoal e independente. Não possui qualquer vínculo com o TSE, Justiça Eleitoral, partidos políticos ou candidatos. Todos os dados exibidos são de domínio público e fornecidos oficialmente pelo TSE.

HTML5 Tailwind CSS Chart.js JavaScript (Vanilla) GitHub Pages

✨ Recursos do Painel

🗳️

Dados em Tempo Real

Apuração ao vivo direto da API do TSE, atualizada automaticamente.

📋

Todos os Cargos

Presidente, Governador, Senador, Dep. Federal, Dep. Estadual e Dep. Distrital.

🗺️

Filtros por Região

Norte, Nordeste, Centro-Oeste, Sudeste e Sul — ou selecione UFs individuais.

🔍

Busca Inteligente

Pesquise por qualquer parte do nome, partido, número ou coligação.

🔤

Agrupamento A-Z

Ideal para 700+ deputados: agrupa por inicial do nome com contagem.

🏆

Filtro de Eleitos

Veja apenas candidatos eleitos ou não eleitos com um clique.

🏛️

Totalizadores por Partido

Ranking completo de partidos com votos, eleitos e porcentagens.

💾

Exportação JSON

Exporte dados completos, listas filtradas ou análises em JSON.

📸

Fotos dos Candidatos

Fotos oficiais diretamente da API do TSE para cada candidato.

📈

Análises Avançadas

Rankings, top 10, estatísticas por partido e gráficos interativos.

📊

Ordenação Flexível

Ordene por votos, porcentagem, nome, partido ou número.

📱

100% Responsivo

Funciona perfeitamente em celular, tablet e desktop.
